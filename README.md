# Portfolio Ecommerce — 2026

An independent course version of Jonalene Ryza Abundo's personal portfolio, created for an Ecommerce subject. BeU Eyewear is the highlighted product showcase alongside academic projects, skills, education, and student experience.

## Technology

- HTML, CSS, and vanilla JavaScript
- Responsive design for mobile, tablet, and desktop
- Local MixItUp project filtering with a vanilla JavaScript fallback
- EmailJS contact form and a direct email link
- Roboto typography and the BeU periwinkle palette

## View and deploy

Open `index.html` directly in a browser, or serve this directory with any static web server. Deploy the repository root containing `index.html` and `assets/` to any static hosting service. No npm installation, build step, database, cart, or checkout is required.

The product image is `assets/img/beu-product.png`. Existing article pages and assets are retained. `assets/css/legacy.css` preserves the article styling; the new portfolio styles are scoped to the main page.

## Content and contact

Education, organizational experience, training, and project descriptions are based on the existing portfolio. No new credentials, employment, product specifications, prices, or medical claims have been added. Current academic details beyond the existing records have not been inferred.

Roboto and EmailJS require an internet connection. The form retains the existing EmailJS service/template configuration; delivery and allowed deployment domains must be verified with the account owner. On failure, the form preserves the message and offers email as a fallback. Without JavaScript, use the email link.

Historical articles and the archived CV asset are retained as supplied; the old CV download is not promoted on the refreshed page. Social profiles and historical repository destinations should be checked by the owner before submission.
